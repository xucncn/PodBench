# PodBench

This repository is the official code/data release for the paper:

**PodBench: A Comprehensive Benchmark for Instruction-Aware Audio-Oriented Podcast Script Generation**

## Status

🚧 **Work in progress.**  
We are preparing the public release of the PodBench benchmark and the evaluation toolkit.  
**Data and code will be updated in subsequent commits.**

## Planned Contents

- **Benchmark data** (instructions, input materials, and script generation prompts)
- **Evaluation framework** (Stage2/Stage3 prompts, scoring scripts, and aggregation)
- **Reproducibility** (run scripts, configs, and example outputs)
